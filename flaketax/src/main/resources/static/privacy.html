Privacy in this local demo

The database stores handles, password hashes, virtual point balances, pacts, proof notes and point movements. Passwords are sent using HTTP Basic authentication during local testing, Never use real personal data or expose this version over public HTTP.

You can close an account after its open pacts have settled, Closure replaces its handle and password hash so the old login stops working and the handle becomes available. Previous proof notes, pact data and ledger entries remain for accounting history. Account closure is not complete data erasure.

This is an educational local application. Public deployment requires HTTPS, better session security, user data controls, a real privacy policy and an independent security review
